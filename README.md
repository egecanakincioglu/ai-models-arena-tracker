# ai-models-arena-tracker 🤖

> Automated AI benchmark & LLM arena tracker. Fetches data from top platforms, normalizes scores using Llama 3 (8B), updates raw JSON via GitHub Actions 8x a day, and serves a live Vercel dashboard.

---

## 🚀 Features

* **Automated Pipelines:** Runs 8 times a day via GitHub Actions (Cron).
* **Consensus Scoring:** Fetches and normalizes data from Hugging Face, LMSYS, and top benchmark sites.
* **AI-Powered Insights:** Uses Llama 3 (8B) to generate human-readable commit insights on model performance shifts.
* **Open Source Data:** Provides daily updated `data.json` for researchers and developers.
* **Live Dashboard:** Modern UI deployed on Vercel for instant visualization.
